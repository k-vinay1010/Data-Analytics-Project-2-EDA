# 📊 Data Analytics Project 2 – Exploratory Data Analysis

## 📌 Project Overview

This project is part of the DecodeLabs Data Analytics Industrial Training program.

Project 2 focuses on Exploratory Data Analysis (EDA) using the cleaned dataset prepared during Project 1.

The objective is to uncover patterns, trends, distributions, relationships, and potential outliers in the dataset.

## 🎯 Objectives

- Calculate descriptive statistics
- Analyze product performance
- Identify trends over time
- Detect potential outliers
- Analyze correlations between numerical variables
- Analyze order status and referral sources
- Generate meaningful business insights

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Descriptive Statistics
- IQR Outlier Analysis
- Correlation Analysis
- Data Visualization

## 📂 Project Contents

- `Data_Analytics_Project_2_EDA.xlsx`
- Descriptive Statistics
- Product Analysis
- Time Trend Analysis
- Outlier Analysis
- Correlation Analysis
- Order Status Analysis
- Referral Source Analysis
- Key Business Insights

## 🔍 Key Analysis

The project analyzes:

- Order quantity
- Unit price
- Items in cart
- Total price
- Products
- Order status
- Referral sources
- Time-based sales trends

## 📈 Outcome

The analysis transforms the cleaned dataset from Project 1 into meaningful analytical findings that can support business understanding and decision-making.
